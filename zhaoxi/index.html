一个 App 收下三件事

一笔收支、一条要办的事、一个每年都要记得的日子。它们最后都汇到同一个提醒中心， 锁屏上只有一组通知，不会散成十几条。

主要功能

记账

收入 / 支出 / 转账；分类名称、图标、颜色全都可以自己定； 账户余额由流水自动推导，还能按「最近 5 笔 / 按月」查看某个账户的明细。

还款计划

填本金、年利率、期数，自动算出月供、每期本金与利息、剩余本金。

  • 支持等额本息、等额本金、先息后本、按月付息按年还本
  • 可设「前 N 期只付息」，覆盖「先息后本 + 后期等额本息」的组合还款
  • 按实际放款日按天计息，首期不是整月也能和银行对上
  • 同一家银行 / 同一个人的多笔合并成一条，先看合计，点开才是明细
  • 支持提前还部分本金：月供不变或期数不变，两种都行

记事

纯记录随手记；给记事挂上办理日期就变成待办，到期前提醒。 逾期的会单独成一张卡，可以一键完成、延期或放弃。

重要日子

生日纪念日按年、房租账单按月、婚礼旅行只算一次。 支持农历，填了出生年份还会自动算今年几岁。

为什么它很轻

纯原生 SwiftUI 构建，零第三方依赖。冷启动不到 1 秒，内存约 50MB。 数据只保存在你的设备上，没有广告，没有分析 SDK，没有追踪。
